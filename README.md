# المدير المالي — The Financial Director

موقع ثنائي اللغة (عربي/إنجليزي) يحوّل كشف عمليات شركتك إلى تقرير مالي واضح: قرار الأسبوع، تحذير السيولة، من أين تكسب/تنزف، المخاطر المخفية، وتوصيات مسعّرة بالريال. الأرقام تُحسب بالكود (حتمية)؛ الصياغة فقط لغوية.

## التشغيل

```bash
pip install -r requirements.txt        # أو ثبّت الحزم يدوياً (أسفل)

python app.py                          # تطوير: http://127.0.0.1:5000
python app.py --serve                  # إنتاج (waitress) على المنفذ 5000
```

متغيرات بيئة اختيارية:
- `PORT` — المنفذ (افتراضي 5000)
- `SITE_URL` — رابط الموقع العام (يُستخدم في SEO/الخريطة) مثال: `https://almudir.com`
- `SECRET_KEY` — مفتاح الجلسات (يُولّد تلقائياً إن لم يُحدَّد)
- `RETENTION_SECS` — عمر التقارير المؤقتة قبل حذفها (افتراضي ساعتان)
- `ANTHROPIC_API_KEY` — يُفعّل طبقة قراءة الصور/الملفات الممسوحة
- `FLASK_DEBUG=1` — وضع التطوير فقط

## الأداة عبر الطرفية (CLI)

```bash
python run.py <الملف> --cash 120000 --company "اسم" --lang ar --out تقرير.pdf
python generate_sample.py              # يولّد بيانات_تجريبية.xlsx للتجربة
python test_battery.py                 # 24 اختبار: دقة + حالات حدّية + أمان
```

## الصيغ المدعومة

Excel · CSV · PDF (بجدول) · Word (بجدول) · نص. الصور والملفات الممسوحة عبر طبقة الذكاء الاصطناعي (تحتاج `ANTHROPIC_API_KEY`).

## شكل الإدخال (كشف عمليات)

أعمدة تُتعرّف تلقائياً (عربي/إنجليزي): `التاريخ` · `البيان` · `النوع` · `التصنيف` · `الطرف` · `المبلغ`.
يدعم أيضاً: اشتقاق النوع من إشارة المبلغ (سالب=مصروف)، وأعمدة مدين/دائن منفصلة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `app.py` | خادم Flask — المسارات، الأمان، SEO، تنظيف الملفات |
| `extractors.py` | طبقة استخراج موحّدة لكل الصيغ + نقطة تمديد الذكاء الاصطناعي |
| `engine.py` | التحليل الحتمي — بيانات ومفاتيح فقط، بلا نصوص |
| `i18n.py` | كل الصياغة (عربي/إنجليزي) — واجهة + تقرير |
| `report.py` | مولّد PDF ثنائي الاتجاه (RTL/LTR) |
| `run.py` | تشغيل CLI |
| `templates/` · `static/` | الواجهة (index, result) + CSS/JS/أيقونة |

## الأمان والصلابة

- رؤوس أمان (CSP بـ nonce، nosniff، X-Frame-Options، Referrer-Policy)
- لا تسريب للأخطاء الداخلية للمستخدم (سجل داخلي فقط)
- حذف الملف المالي الخام فور التحليل + تنظيف دوري للتقارير القديمة
- تحقق صارم من الصيغ وحدّ حجم 25MB ومعالجات 400/413/404/500 ودّية
- تحميل محمي من اجتياز المسارات (تحقق بنمط صارم)

الأرقام تُحسب بالكود (دقيقة، لا تخمين)؛ الذكاء الاصطناعي — عند تفعيله — يقرأ الملفات فقط. التقديرات المستقبلية تُعرض بوضوح كافتراضات مبنية على استمرار الاتجاه.
